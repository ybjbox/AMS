## 6. 业务单据（最近三轮改动，最容易接手就改坏的一块）

版面事实源是 `src/pages/BusinessForms/lib/layout.ts`（单位 **twips**，取自纸质原件的 OOXML），三条输出链路共用它：页面预览、独立打印窗口（`printHtml.ts`）、`.docx`（`docxFile.ts`）。**只改一条 = 制造回归。**

机主定下的口径（2026-09-27 三轮）：

1. 整块**水平居中**：表格左偏移 `tableIndent = -884`（原件实测是 -612，即整块偏右 4.8mm），左右各留 16.10mm。
2. 日期行**右对齐**到「表格右边往里缩 575 twips = 10.14mm」这条几何基线；`.docx` 用 `w:jc=right` + `w:ind right="-309"` 对同一条线。**不要退回"居中 + 前导空格"**（那套靠字宽估算，字体度量一变就飘，且 printHtml 的 CSS 测试专门钉了它不能回来）。
3. 竖向用 **auto margin** 而不是 `justify-content:center`：内容超出时 auto margin 归零、从 8mm 上边距往下排；flex 居中会把超出推到纸外、打印裁掉第一行。
4. **一张纸固定上下两格、每格 140.49mm 定高**，分界线 = `marginTop + SLOT_H = 148.50mm` = **A4 对折线**（上下页边距对称才成立，有单测锁）。机主要的是"对折一刀裁得开"，所以**单条也必须用上半格**、下半格打一张空白单（`BLANK_FORM`：同骨架、栏目名在、值全空）。
5. 「一张纸 1 条 / 2 条」开关**已删除**（多条之后语义重复），连带撤掉按账号存的 saved-items kind `business-forms-print`（前后端两份清单同步回退）。别再把它加回来。
6. 正文超过半页（**>6 行**）的那条**独占一张且不补空白单**（补了必溢出成第二页 = 凭空多一张纸），界面点名第几条、约几行。原尺寸不缩放是硬要求。
7. 多页文档第二页起 `break-before: page`；`.docx` 一条一个分节 = **一页一条**（Word 是给人接着改的，与打印刻意不同）。
8. 条目模型在 `lib/items.ts`：`BusinessFormItem = BusinessForm + id/bodyEdited/locked`；"正文跟模板走、被手打过就不再覆盖"这条规则只有这一份，四个入口共用。深链 `?employeeId=` 只锁第一条。
9. 左右留白实测差 0.26mm = **1 个设备像素取整，不是版面误差，别去"修"它**。
10. 条目内容**不跨刷新保存**（现在没有任何跟账号走的打印参数）。要做草稿持久化是另一件事，别顺手加。

## 8. 本地环境陷阱（Windows / Git Bash）

- `python` 是 Microsoft Store 的 stub，`strings`/`make`/`docker` 都没有 —— **别把"命令没输出"当成"没有内容"**（假阴性陷阱）。技能里的 `search.py` 在这台机器上跑不了。
- 仓库是 **CRLF**：用 `\n` 做字符串精确匹配会失败；写 codemod 要 EOL 感知。
- `git add`/`diff` 会刷一堆 "LF will be replaced by CRLF" warning，是噪音。
- 登录限流：连跑 e2e 会撞 5 分钟登录限流；`e2e/.auth/user.json` 的 storageState 按端口分区（token 在 localStorage）。
- 恢复备份需要**独占** `DATA_DIR`；`setupFiles` 里不要 import `db.ts`；临时账号先 change-password。
- 生产 CSP 是 `script-src 'self' 'nonce-…'`：往页面里注入探针（如 axe）必须走同源被拦截的 URL，不能 `addScriptTag({content})`。
- 主题存在 `app_settings_theme`，值是 zustand 信封 `{"state":{…,"theme":"system"},"version":0}` —— 塞裸字符串会让两轮测试都跑亮色（本会话踩过，两次证据全废）。
- 隐藏视口下 `browser-use` 的 click/screenshot 可能不可用：改用 snapshot / fill / `evaluate_script`；读 computed style 要注意过渡中间态（用轮询）。
